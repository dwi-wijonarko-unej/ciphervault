Privasi Anda adalah fondasi desain CipherVault. Dokumen ini menjelaskan data apa yang kami kumpulkan, bagaimana kami melindunginya, dan hak Anda atas data tersebut, sejalan dengan Undang-Undang Nomor 27 Tahun 2022 tentang Pelindungan Data Pribadi (UU PDP).

1. Data yang Kami Kumpulkan

  • Data akun: username dan alamat email yang Anda berikan saat registrasi.
  • Kredensial (terproteksi): password di-hash menggunakan bcrypt; salt dan derived key hash disimpan menggunakan PBKDF2 (100.000 iterasi). Plaintext password tidak pernah disimpan.
  • Metadata file: nama file asli, ukuran, tipe MIME, dan metadata enkripsi (ukuran matriks, rasio split, decision trace AI Selector).
  • Log aktivitas: tindakan seperti login, upload, download, share, dan revoke untuk audit keamanan.
  • Token teknis: JWT sesi dan API Key (hash) untuk autentikasi.

Yang TIDAK kami kumpulkan: kami tidak melacak penjelajahan web Anda, tidak memasang iklan pihak ketiga, dan tidak menjual data Anda.

2. Bagaimana File Anda Disimpan

Setiap file yang Anda unggah dienkripsi sebelum meninggalkan proses aplikasi, menggunakan arsitektur hibrida berlapis:

  • Lapisan 1 — UHC (Unimodular Hill Cipher): plaintext dienkripsi dengan matriks kunci yang dihasilkan dari logistic map.
  • Lapisan 2 — AES-256-CBC: output UHC dibungkus penuh (cascade) dengan AES, IV acak per file.
  • Penyalutan kunci sesi: kunci sesi di-wrap dengan user key (PBKDF2-derived) dan RSA-OAEP global.

Hanya ciphertext yang tersimpan di server. Plaintext file Anda tidak pernah menulis ke disk. Tanpa password Anda, file tidak dapat didekripsi—termasuk oleh kami.

3. Penggunaan Data

  • Operasional: menyediakan, memelihara, dan meningkatkan Layanan.
  • Keamanan: mendeteksi aktivitas mencurigakan, menegakkan kontrol akses (RBAC), dan menyelidiki insiden.
  • Audit: log aktivitas dipakai untuk akuntabilitas dan, bila diwajibkan hukum, investigasi.
  • Komunikasi: mengirim notifikasi penting terkait akun dan perubahan layanan.

4. Berbagi & Pengungkapan Data

Anda memegang kendali penuh atas berbagi data:

  • Sharing antar user: hanya terjadi atas inisiatif Anda melalui fitur share. Kunci sesi di-wrap ulang untuk penerima.
  • Public link: Anda membuat dan mencabut sendiri; dapat dilindungi password dan masa berlaku.
  • Permintaan hukum: kami hanya akan mengungkap data bila diwajibkan oleh hukum yang berlaku, dan akan berupaya memberi tahu Anda kecuali dilarang.

5. Retensi & Penghapusan Data

  • Data akun disimpan selama akun aktif.
  • Log aktivitas disimpan untuk keperluan audit sesuai kebijakan internal (lihat dokumentasi retensi).
  • Saat Anda menghapus akun, file dan data terkait dihapus permanen dari penyimpanan dan database.
  • Cadangan (backup) terenkripsi dapat mempertahankan data sementara hingga siklus rotasi selesai.

6. Keamanan

  • Enkripsi at-rest untuk seluruh file (UHC + AES cascade) sebagaimana dijelaskan di atas.
  • RBAC (Role-Based Access Control): peran admin dan user membatasi akses ke fitur teknis.
  • Verifikasi integritas SHA-256 saat download untuk mendeteksi manipulasi ciphertext.
  • Database produksi menggunakan PostgreSQL dengan koneksi terisolasi antar-container.

Detail prosedur insiden tersedia di Prosedur Data Breach.

7. Hak Pengguna (UU PDP)

  • Akses: meminta salinan data pribadi yang kami simpan.
  • Koreksi: memperbaiki data yang tidak akurat.
  • Penghapusan: menghapus akun beserta seluruh data terkait.
  • Penarikan persetujuan: menghentikan pemrosesan tertentu (dapat memengaruhi ketersediaan Layanan).
  • Ajukan permintaan via privacy@ciphervault.io. Kami merespons dalam jangka waktu yang wajar sesuai UU PDP.

8. Cookie & Token Sesi

CipherVault tidak menggunakan cookie pelacak pihak ketiga. Kami menyimpan preferensi tema di localStorage dan JWT sesi di sisi klien (client-side). API Key disimpan hanya dalam bentuk hash di server.

9. Kontak

Pertanyaan terkait privasi: privacy@ciphervault.io

Your privacy is a foundational design principle of CipherVault. This document explains what data we collect, how we protect it, and your rights over that data, in accordance with Law No. 27 of 2022 on Personal Data Protection (UU PDP).

1. Data We Collect

  • Account data: username and email address you provide during registration.
  • Credentials (protected): passwords are hashed using bcrypt; salt and derived key hashes are stored using PBKDF2 (100,000 iterations). Plaintext passwords are never stored.
  • File metadata: original filename, size, MIME type, and encryption metadata (matrix size, split ratio, AI Selector decision trace).
  • Activity logs: actions such as login, upload, download, share, and revoke for security auditing.
  • Technical tokens: session JWT and API Key (hash) for authentication.

What we do NOT collect: we do not track your web browsing, do not serve third-party ads, and do not sell your data.

2. How Your Files Are Stored

Every file you upload is encrypted before leaving the application process, using a layered hybrid architecture:

  • Layer 1 — UHC (Unimodular Hill Cipher): plaintext is encrypted with a key matrix generated from a logistic map.
  • Layer 2 — AES-256-CBC: UHC output is fully wrapped (cascade) with AES, using a random IV per file.
  • Session key wrapping: session key is wrapped with user key (PBKDF2-derived) and global RSA-OAEP.

Only ciphertext is stored on the server. Your file plaintext is never written to disk. Without your password, files cannot be decrypted — including by us.

3. Data Usage

  • Operational: providing, maintaining, and improving the Service.
  • Security: detecting suspicious activity, enforcing access controls (RBAC), and investigating incidents.
  • Audit: activity logs are used for accountability and, where required by law, investigations.
  • Communication: sending important notifications regarding your account and service changes.

4. Data Sharing & Disclosure

You maintain full control over data sharing:

  • Peer sharing: occurs only at your initiative through the share feature. Session keys are re-wrapped for the recipient.
  • Public links: you create and revoke them yourself; they can be protected with a password and expiration.
  • Legal requests: we will only disclose data when required by applicable law, and will endeavor to notify you unless prohibited.

5. Data Retention & Deletion

  • Account data is retained while the account is active.
  • Activity logs are retained for audit purposes per internal policy (see retention documentation).
  • When you delete your account, files and related data are permanently deleted from storage and the database.
  • Encrypted backups may retain data temporarily until the rotation cycle completes.

6. Security

  • At-rest encryption for all files (UHC + AES cascade) as described above.
  • RBAC (Role-Based Access Control): admin and user roles restrict access to technical features.
  • SHA-256 integrity verification on download to detect ciphertext tampering.
  • Production database uses PostgreSQL with isolated inter-container connections.

Incident procedure details are available at Data Breach Procedure.

7. User Rights (UU PDP)

  • Access: request a copy of the personal data we hold.
  • Correction: correct inaccurate data.
  • Deletion: delete your account along with all associated data.
  • Withdrawal of consent: stop certain processing (may affect Service availability).
  • Submit requests via privacy@ciphervault.io. We respond within a reasonable timeframe as required by UU PDP.

8. Cookies & Session Tokens

CipherVault does not use third-party tracking cookies. We store theme preferences in localStorage and session JWT on the client side. API Keys are stored only as hashes on the server.
